# Dotfiles

## Requirements

- git
- nodejs
- GNU Stow
- nvim
  - luarocks
  - neovim
  - nerd fonts
  - lazygit
  - tectonic
  - npm

## Usage

1. clone this repo: `git clone https://github.com/FilipVondrak/dotfiles.git ~/.dotfiles && cd ~/.dotfiles`
2. install
    - to install everything use: `stow */`
    - to install only selected packages:q use: `stow <package>`
